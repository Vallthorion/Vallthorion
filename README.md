## About Me

I am **Yan Ardiansyah**, a student at **SMKN 6 Malang**, majoring in Sistem Informatika, Jaringan, dan Aplikasi (SIJA).

I am interested in web development, software engineering, network technologies, and building practical applications through programming.

My current focus is developing modern web applications, improving software architecture, and exploring the integration of APIs, databases, networking, and IoT systems.

- Frontend and backend development
- Laravel, React, and Next.js

- UI/UX design and application development
